# Genie Reader

macOS download for **Genie Reader** — a local, private
text-to-speech app that turns articles, PDFs, and pasted text into spoken
audio, entirely on-device.

- **Site:** https://geniereader.com
- **Download:** see [Releases](https://github.com/mazen-kasser/genie-reader/releases)

This repo hosts only the download page and release binaries — no application
source code.
