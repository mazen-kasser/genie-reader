Installing: open the downloaded .dmg and drag Genie Reader into your Applications folder. The app is signed and notarized by Apple, so it opens normally — no security warnings. Genie Reader also expects Ollama for the article rewriting step; it'll offer to install this automatically on first run if it's missing.
